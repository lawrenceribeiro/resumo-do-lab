# resumo-do-lab
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO

A computação em nuvem é o fornecimento de serviços de computação pela internet.

Temos 3 tipos de nuvens:
1) Nuvem privada, as organizações cria o seu própio data center
2) Nuvem pública, as organizações usa serviço de computação de terceiros.
3) Nuvem híbrida, as organizações usam nuvem privada mais nuvem pública.

Cada organização tem que avaliar a sua necessidade levando em conta o CapEx e OpEx.
